<h3 align="left">🚢 What I've Shipped</h3>

🏛️ **[ciphuanuco.org.pe](https://ciphuanuco.org.pe)** — institutional platform for the Peruvian Association of Engineers (Huánuco Chapter). Member portal, admin management and a real-time dashboard, with **Mercado Pago** payments, **SUNAT** electronic invoicing, **RENIEC** identity verification and digitally signed **PDF + QR** certificates.<br>

🎓 **[Copiloto](https://gestiondetesis.sistemasudh.com)** — my own SaaS in production: guides a thesis from proposal to defense across student, advisor, jury and faculty, with role-based access and a configurable approval workflow.<br>

🧩 **Convoca** — recruitment and selection platform: **NestJS + Prisma + PostgreSQL**, async job queues on **Redis / BullMQ**, JWT auth, role-based permissions, OpenAPI-documented API, **OCR** document screening and **MediaPipe** proctoring. Frontend in **Next.js**. Covered by **Vitest** and **Playwright**.<br>

💰 **SIGEC / Recuperos** — debt collection system: bulk XLSX ingestion preserving source data, collection business rules and partial/full payment tracking.<br>

👁️ **Computer Vision** — real-time drowsiness detection and facial recognition pipelines with **YOLO, OpenCV, MediaPipe** and **PyTorch**.<br>

> Most of the code above lives in private repositories (client and institutional work) — the live URLs are the evidence.
